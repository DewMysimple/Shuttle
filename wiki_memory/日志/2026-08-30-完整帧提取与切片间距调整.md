# 2026-08-30｜完整帧提取与切片间距调整

- 时间：2026-08-30（北京时间）
- 类型：`feature`
- 状态：`完成`
- 目标：让网页使用兰花源动画的全部整数帧，并增加相邻时间切片的空间距离。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的决策

- 兰花 `.blend` 的实际动画范围为 1–166 帧，本轮不再按 76 个状态均匀采样。
- 导出脚本逐帧处理 `range(scene.frame_start, scene.frame_end + 1)`，生成 166 张透明 PNG；manifest 的 `count` 与 `frames` 列表保持一致。
- 前端先读取 `slice-manifest.json`，再按清单数量加载纹理，不再把 76 写死在运行时代码中。
- 时间隧道步进由 X `0.10` / Z `0.18` 调整为 X `0.16` / Z `0.30`；卡片尺寸、当前帧中心锚定和仅时间切片运行时保持不变。

## 检查与操作

- 重新检查 `兰花_形态1.blend`、Blender 5 和外部 `OrchidMeshGrp.abc` 缓存路径。
- 更新 `src/main.js`、`scripts/export_blender_assets.py` 和入口加载文案。
- 使用 `F:\Blender\blender.exe` 结合有效外部 Alembic 缓存重新导出 `public/assets`。
- 同步更新 README、PROJECT_MEMORY、当前状态页、模块知识页和 ADR-007；新增 ADR-008 记录完整帧策略。

## 文件变更

- `src/main.js`：manifest 驱动切片数量，使用动态 `frameFloat` 范围，增大 X/Z 空间步进。
- `scripts/export_blender_assets.py`：从 76 个均匀样本改为源场景全部整数帧。
- `public/assets/slices/`：生成 `frame-001.png` 至 `frame-166.png`。
- `public/assets/slice-manifest.json`、`public/assets/flower.glb`：按完整帧重新生成。
- `README.md`、`PROJECT_MEMORY.md`、`wiki_memory/`：同步当前架构、约束、决策和运行说明。
