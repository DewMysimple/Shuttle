# 播放光晕运行时错误修复

## 现象

播放光晕调整后，页面文字和按钮仍然可见，但主体、时间切片和环境光晕全部不可见；右上角状态仍会显示“正向播放”。

## 根因

`updateAtmosphere()` 为轨道光环增加按序号衰减的播放亮度时，表达式使用了 `index`，但 `atmosphereRings.forEach()` 的回调仍只声明了 `ring`。浏览器在每帧执行到该表达式时抛出 `ReferenceError`，停止 `requestAnimationFrame` 后续渲染；DOM UI 因此保留最后一次状态，看起来像只有 3D 场景消失。

## 修复

- 将轨道光环回调参数改为 `(ring, index)`，使播放增益使用合法的环线序号。
- 保留本次纵深时间游标、横深残影和局部光晕的视觉调整，不修改 PNG、manifest、`flower.glb`、Blender 源文件或交互边界。

## 验证

- `node --check src/main.js` 通过。
- `npm run build` 通过。
- `git diff --check` 通过。
- 静态断言确认轨道光环回调声明 `index`，并确认未改动运行资产。
- 本地 Vite 入口、manifest 和 166 张 PNG 资源回归均返回 HTTP 200。
- 当前环境没有浏览器自动化入口，未执行真实浏览器控制台无异常和逐帧视觉验收。

## 结果

修复渲染循环中断问题，3D 主体、时间切片、残影与光晕可以继续渲染；之前的“全不可视”是代码运行时错误，不是透明度或原始材质问题。
