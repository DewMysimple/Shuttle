# 主时间切片色彩与材质强化

## 目标

在不重新导出 PNG、不修改 Blender 源材质和不改变交互的前提下，让当前主时间切片具有更鲜明的珊瑚红/玫红色、更强的局部对比和更清楚的材质层次。

## 确认的决策

- 仅调整网页运行时；保留 166 张透明 PNG、manifest、`flower.glb` 和所有播放/旋转/缩放行为。
- 当前帧图像透明度提高到约 `0.99`，相邻、中距离、远距离切片分别压低到约 `0.12–0.20`、`0.05–0.09`、`0.012–0.03`。
- 新增 `sliceWarmth` shader uniform，当前帧连续使用最高约 `1.90` 饱和度、`1.29` 对比度和暖珊瑚色偏移；焦点使用更明显的暖珊瑚加法微光、轮廓和轻微尺度差异。
- 降低 CSS 白色 screen 雾层与 haze 动画强度，在主体背后加入低强度深玫红局部对比区；不引入后处理 Bloom。

## 检查范围

- 检查 `src/main.js` 的切片 shader、透明度分级、微光、轮廓和尺度逻辑。
- 检查 `src/style.css` 的背景渐变、screen veil 和 haze 呼吸强度。
- 检查 README、`PROJECT_MEMORY.md`、当前约束、ADR-014 和 Three.js 模块知识页是否同步当前视觉规则。

## 文件变更

- `src/main.js`：强化当前帧连续饱和度/对比度/暖色偏移，压低非焦点透明度，提高焦点微光、轮廓和尺度差异。
- `src/style.css`：增加主帧背后的深玫红对比区，降低白色 veil 与 haze 的覆盖。
- `README.md`、`PROJECT_MEMORY.md`、`wiki_memory/`：同步当前焦点视觉参数和验证记录。

## 测试摘要

- `node --check src/main.js` 通过。
- `npm run build` 通过；仅保留项目原有的 Three.js bundle 体积提示。
- `git diff --check` 通过；确认未修改 PNG、Blender、manifest 或 `flower.glb`。
- 当前环境未提供可用的本地 Chrome/Playwright 自动化入口，浏览器逐状态视觉体验仍需在真实浏览器或设备上复核。

## 结果

网页运行时已完成主时间切片的鲜艳色彩、焦点对比、暖珊瑚微光和材质层次强化，且保持时间切片结构和现有交互不变。

## 遗留问题和下一步

- 在真实 Chrome、Edge、Safari 和移动设备上确认主帧饱和度、微光强度、播放连续性、侧面层次和 reduced-motion 表现。
- 如果真实设备上花瓣仍偏白，下一步再单独评估 Blender 色彩管理与 PNG 重新导出，不在本任务中扩大范围。
