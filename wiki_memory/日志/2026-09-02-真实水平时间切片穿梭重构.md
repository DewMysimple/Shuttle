# 2026-09-02｜真实水平时间切片穿梭重构

## 目标

研究两段参考 MP4 与改造前录屏，替换为指定 `WING_FLAP_ONLY` 蝴蝶源，修复旧实现“中心平面换纹理播放”的伪时间切片，并按用户补充示意实现水平、平行、不相交的真实逐帧平面。

## 确认的决策

- 逐帧照片由相机沿世界 Z 轴正对模型 X-Y 平面采样，使用固定正交视角和身体几何中心构图。
- 91 个源整数帧对应 91 张独立 PNG 和 91 个独立 Three.js 平面；运行中不交换纹理。
- 网页平面位于 X-Z 水平面并沿 Y 轴分层。展开后从斜侧看到互不相交的水平层，而不是同一立面上互相覆盖的卡片带。
- 普通滚轮逐帧穿梭；左键径向拖拽展开；右键或 `Alt + 左键` 检查侧视；修饰键加滚轮缩放。
- 删除用户指出的额外中心装饰框，并同时移除其他会被误读为伪切片的门户框。

## 主要变更

- 重写 `scripts/export_butterfly_slices.py`：固定 Z 轴正交相机、身体中心、逐整数帧、透明碎片清理和暂存后原子发布。
- 重新生成 `public/assets/slices/frame-001.png` 到 `frame-091.png`，并更新 manifest 的采样/视角/展示平面契约。
- 重写 `src/main.js`：移除 `focusLayer`/`focusTrail`/动态纹理替换，实现静态纹理一一绑定、Y 轴相机穿梭、径向展开和水平层侧视。
- 重构 `index.html` 与 `src/style.css`：粉彩单屏舞台、状态控件、键盘/无障碍说明和 reduced-motion；移除额外中心框。
- 更新根 README、Source 说明、当前状态、知识页与决策记录。

## 验证摘要

- Blender 5.0 完整导出 91 帧成功。
- 资产脚本验证 91 个 PNG 全部存在、全部为 768×768 RGBA、SHA-256 均不重复；manifest 源帧连续 1 到 91。
- 抽查第 1、15、30、45、60、90 帧，确认开翼、半开、合翼姿态均来自固定 X-Y 正视构图，低透明度远端碎片已清除。
- `node --check src/main.js` 与 `npm run build` 通过；Vite 仅报告 Three.js 主包超过 500 kB 的常规警告。
- Chrome 1440×1000 截图验证收拢正视、展开水平分层和额外中心框移除。
- 静态搜索确认不存在 `focusLayer`、`focusTrail`、运行时 `.map =` 或旧 X 轴时间排列。

## 遗留问题

- 仍需在真实触控板、鼠标和移动设备验证手感及 91 张纹理的显存占用；不阻塞当前交付。
