# 当前帧聚焦与微光强化

## 目标

降低非当前时间切片的视觉存在感，让播放中的当前兰花切片拥有最完整的色彩与细节；增加微弱的轮廓光和呼吸反馈，但避免整组切片再次叠加成白雾。

## 确认的决策

- 当前帧图像透明度目标约 `0.96`，相邻、中距离、远距离切片依次降低到约 `0.16–0.30`、`0.06–0.14`、`0.02–0.06`。
- 当前帧使用更强的饱和度和对比度；其他切片不改写 PNG，只降低透明度和色彩存在感。
- 每张切片增加低强度暖粉色加法混合副层，使用连续 `frameFloat` 权重跟随当前焦点；微光约 `1.7s` 周期轻微呼吸，强度约 `3.8%–6.6%`。
- 收拢时仍以当前四舍五入帧为清晰主体；`prefers-reduced-motion` 下取消呼吸但保留静态焦点光。
- 不修改 166 张 PNG、manifest、Blender 源文件、空间排列和既有播放/旋转/缩放交互。

## 检查范围

- 检查 `src/main.js` 的切片材质、焦点透明度、色彩 shader uniform 和渲染循环。
- 检查 README、`PROJECT_MEMORY.md`、当前状态、模块知识和 ADR 是否描述同一套焦点规则。
- 验证语法、构建、差异空白、记忆索引/检查和运行资产数量；浏览器人工体感复核作为后续检查项记录。

## 文件变更

- `src/main.js`：新增焦点微光副层，调整图像、卡片、边缘线的透明度层级和焦点色彩分级。
- `README.md`、`PROJECT_MEMORY.md`：补充当前帧视觉优先级与微光规则。
- `wiki_memory/决策/ADR-014-当前帧色彩聚焦与微光.md`：记录长期视觉决策。
- `wiki_memory/当前状态/`、`wiki_memory/知识/模块/`：同步当前有效实现。

## 测试摘要

- `node --check src/main.js`、`npm run build`、`git diff --check` 均通过；构建仅保留既有的 Three.js bundle 体积提示。
- `python wiki_memory/工具/memory_lint.py index`、`python wiki_memory/工具/memory_lint.py check` 均通过，索引包含 57 篇 Markdown 页面。
- 静态断言通过：manifest 为 166、PNG 为 166，存在 `AdditiveBlending`、1.7 秒微光周期、reduced-motion 静态分支，源码无 `GLTFLoader`、`AnimationMixer` 或 `flower.glb` 请求。
- 资源 GET 通过：独立 Vite 端口上的入口、manifest 和 166 张 PNG 全部 HTTP 200；当前 `5173` 端口由其他 Vite 应用占用，因此使用 `4173` 完成检查。
- 浏览器人工首帧/中段/尾帧、播放连续性、收拢态和 reduced-motion 体感复核尚未执行，保留为真实设备验收项。

## 结果

源码与文档修改已完成，静态、构建、记忆和资源验证通过；视觉体感复核留待真实浏览器设备。

## 遗留问题和下一步

- 仍需在真实 Chrome、Edge、Safari 和移动设备上确认微光强度、主体色彩和显存开销。
- 如设备上仍有过曝，应优先降低 `FOCUS_GLOW_BASE` 与 `FOCUS_GLOW_BREATH`，不要先提高远端切片透明度。
