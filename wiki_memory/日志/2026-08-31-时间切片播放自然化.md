# 时间切片播放自然化

## 目标

解决播放时整组矩形切片高速扫过镜头、主体不稳定和切片感过重的问题。参考视频只作为构图与运动质感参考，不把滚动误读为时间播放入口；保留现有长按、按钮、滚轮缩放和拖拽旋转边界。

## 确认的决策

- 166 张时间轴切片以 `timelineCenter = (sliceCount - 1) / 2` 固定在世界 Z 轴深度序列中，`spread` 只控制展开/收拢距离，播放中的 `frameFloat` 不再推动整组切片位移。
- 新增固定视觉中心的 `focusLayer`，使用 `floor(frameFloat)`、`ceil(frameFloat)` 和小数部分对当前/下一张 PNG 连续交叉淡化；主焦点继续使用最高透明度、饱和度、对比度、暖珊瑚色偏移、轻微放大和局部微光。
- 播放中最多显示 5 层 `playbackTrail`，按方向从当前焦点后方取有限历史/未来帧，以递减透明度、轻微横纵偏移和尺度差异模拟连续飞行轨迹，不显示规则卡片边框。
- 播放期间降低固定时间轴的卡片、轮廓和远端图像透明度；暂停后通过阻尼恢复普通时间轴展示，焦点层继续显示当前帧。
- 相机焦点取消随 `frameFloat` 的额外漂移；`prefers-reduced-motion` 下关闭残影漂移和背景呼吸，只保留稳定主焦点与连续帧交叉淡化。
- 不修改 PNG、manifest、`flower.glb`、Blender 源文件、导出脚本，不新增滚轮时间控制或拖拽展开手势。

## 文件变更

- `src/main.js`：拆分固定时间轴与播放焦点，新增 `focusLayer`、当前/下一帧交叉层和 `playbackTrail`，移除播放期间的整组 Z 轴位移与相机帧漂移。
- `src/style.css`：增加 `.slice-stage.is-playing` 播放状态，降低播放中的白色雾层和时间轴结构，保持粉彩背景与局部深玫红对比。
- `README.md`、`PROJECT_MEMORY.md`、`wiki_memory/`：同步新的播放数据流、残影策略、交互边界和验证状态。

## 测试摘要

- `node --check src/main.js`、`npm run build`、`git diff --check` 通过；构建仅保留既有的 Three.js bundle 体积提示。
- 静态检查确认存在固定 `focusLayer`、当前/下一帧交叉淡化、有限残影和 reduced-motion 分支；确认源码不再用 `frameFloat` 推动整组切片沿 Z 轴移动，也不再使用旧的相机帧漂移。
- `memory_lint.py index`、`memory_lint.py check` 通过，索引包含 59 篇 Markdown 页面；本地 Vite 资源回归通过，入口、manifest 和 166 张 PNG 均返回 HTTP 200。
- 需要在真实 Chrome、Edge、Safari 或移动设备上补做首帧/中段/尾帧、正放/倒放、暂停恢复、旋转侧面和 reduced-motion 的视觉体感验收；当前环境未提供浏览器自动化入口。

## 结果

播放架构已从“整组切片移动”改为“固定时间轴 + 中心主焦点 + 有限播放残影”。这让主体姿态变化成为播放中的主要运动信号，保留时间隧道的空间结构，同时避免规则卡片墙高速扫过镜头。
