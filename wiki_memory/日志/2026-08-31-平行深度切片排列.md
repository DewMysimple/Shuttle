# 2026-08-31｜平行深度切片排列

- 时间：2026-08-31（北京时间）
- 类型：`ui`
- 状态：`完成`
- 目标：修复卡片全部位于同一平面造成的“拉长斜面”效果，使时间切片成为平行、有间隔、不相交的独立平面序列。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 触发原因

- 用户指出当前 X 轴排列在侧面观察时所有卡片共面，卡片边缘相互重叠，和参考图中分开的平行卡片不一致。
- 需要保留当前帧中心锚定、前序切片不可视、播放、旋转和缩放等既有交互。

## 已确认的决策

- 将空间排列轴改为卡片法线方向的世界 Z 轴，而不是继续沿 X 轴共面排放。
- 使用 `offset = index - frameFloat`，当前帧位置固定为 `(0, 0, 0)`。
- 使用 `SLICE_DEPTH_STEP = 0.42`；每个后续切片位置为 `(0, 0, -offset × 0.42 × spread)`，卡片自身 `rotation.x/y/z` 保持为 0。
- 保留统一 `rotationRig`、当前帧聚焦缩放、透明度分级、右侧播放按钮、长按正放/倒放以及环境动效；环境动效只作用于整体组，不改变切片的平行几何。

## 实施内容

- 更新 `src/main.js`：删除 `LINE_STEP`，增加 `SLICE_DEPTH_STEP`，将切片位置改为 Z 深度分层，并保留切片自身零旋转。
- 更新 `README.md`、`PROJECT_MEMORY.md`：把当前布局描述改为平行深度序列，并说明正面嵌套与侧面分离的观察结果。
- 更新 `wiki_memory/当前状态/` 与 `wiki_memory/知识/模块/`：同步当前空间布局、约束、架构和动效说明。
- 将 ADR-011 标记为 `superseded`，新增 ADR-012 作为当前空间构图决策；保留旧决策和旧日志，不删除历史。
