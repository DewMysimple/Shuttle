# 2026-08-31｜直线时间切片排列

- 时间：2026-08-31（北京时间）
- 类型：`ui`
- 状态：`完成`
- 目标：把当前 X+Z 时间隧道切片改成正面平行、沿单一水平直线排列，消除斜向、弯曲和 S 形视觉路径。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的决策

- 用户确认采用“正面朝向保持一致、沿世界 X 轴排成直线”的布局。
- 当前帧仍使用 `offset = index - frameFloat` 锚定在 X=0；播放前序裁切、长按正放/倒放、右侧按钮、滚轮缩放和统一转台旋转均保留。
- 采用 `LINE_STEP = 0.30`，展开时只改变 X 坐标；切片自身 Y/Z 坐标和 X/Y/Z 旋转均为 0。
- `cameraFocusPoint.z` 调整为 0，使固定相机的缩放焦点与直线切片平面一致。

## 实施内容

- 更新 `src/main.js`：移除 `DEPTH_STEP`、`LATERAL_STEP`，用 `LINE_STEP` 计算直线位置；删除切片逐片漂移和逐片旋转，保留整体切片组呼吸、透明度层级和环境动效。
- 更新 `README.md`、`PROJECT_MEMORY.md`：记录新的直线排列、间距和当前帧中心规则。
- 更新 `wiki_memory/当前状态/`、`wiki_memory/知识/模块/`，并将 ADR-007 标记为 `superseded`，新增 ADR-011 作为当前空间布局决策。
