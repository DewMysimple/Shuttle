# 2026-08-31｜俯仰范围与完整时间轨迹调整

## 目标

根据用户最新要求，扩大自由视角俯仰范围、增加相邻时间切片之间的真实间距，并恢复播放过程中当前帧之前历史切片的可见性。

## 确认的实现决策

- `pitchTarget` 的边界由 ±45° 改为 ±90°；屏幕向下拖动仍为俯视，向上拖动仍为仰视，水平和垂直输入保持双轴独立，斜向拖动同时生效。
- `SLICE_DEPTH_STEP` 由 `0.42` 提升为 `0.62`；全部时间切片继续保持正面平行，沿世界 Z 轴等距分层。
- 移除 `index < floor(frameFloat)` 的历史帧裁切；所有 166 张切片始终设置为可见，`frameFloat` 只负责当前帧中心锚定、空间偏移和距离透明度分级。

## 修改范围

- 更新 `src/main.js` 的俯仰边界、深度步长和切片可见性逻辑。
- 更新 `README.md` 与 `PROJECT_MEMORY.md` 的当前交互和验收基线。
- 更新 `wiki_memory/当前状态/`、`wiki_memory/知识/` 与相关 active 决策；将旧的 ADR-012 标记为 superseded，并新增 ADR-013 记录当前规则。

## 验证

- 已执行语法检查、生产构建、Git 空白检查、结构化记忆索引和 lint。
- 已检查源码不存在历史切片隐藏分支，且 `SLICE_DEPTH_STEP` 与 ±90° 边界均写入当前实现。
- 浏览器中的手动拖拽到 ±90°、中段播放完整历史轨迹和侧面间距尚未在本轮通过自动化浏览器工具执行，需在本地页面中复核。

## 结果

代码与文档已完成，运行时不再因播放进度隐藏前序切片；深度序列的相邻间距更大，视角可到达上下 90° 边界。

## 待确认长期记忆

- 将“全部时间帧持续可见、仅按距离淡化”作为当前时间轨迹规则。
- 将 `SLICE_DEPTH_STEP = 0.62` 作为当前平行深度切片的默认间距。
- 将 ±90° 作为当前俯仰上限，不继续扩大到超过极点的范围。
