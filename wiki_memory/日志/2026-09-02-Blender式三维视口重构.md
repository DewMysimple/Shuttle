# Blender 式三维视口重构

## 目标

把仍受自动时间轴相机约束的画面改造成可围绕整组 91 个实体切片自由旋转、平移、缩放的三维检查视口，同时保留逐帧实体映射、水平平行层级和固定当前帧构图。

## 确认的决策

- 默认从中位第 46 帧进入展开的三维透视总览，视口枢轴位于整组切片体中心，不再落在某个 2D 图层上。
- 采用 Blender 风格核心输入：中键旋转、`Shift + 中键` 平移、滚轮缩放；时间步进改为 `Alt + 滚轮`，层距径向拖拽改为 `Alt + 左键`，避免抢占视口导航。
- 时间选择和自由相机解耦。总览模式切帧不改写用户相机；当前帧模式才沿 Y 轴跟随所选实体平面。
- 提供透视、前视、侧视和当前帧四个预设；`Home`/`R` 框显全部，数字键盘 `1`/`3`/`7` 对应检查视角。
- 恢复卡片、轮廓和图像的深度测试，并加入仅在斜视时显现的空间网格，强化真实层间关系。

## 检查与修改

- 审计 `src/main.js` 后确认旧问题来自自动相机每帧追随 `focusY`、中心左键手势竞争和所有切片材质关闭深度测试。
- 重构相机预设、包围体框显、体中心/当前帧双枢轴和相机过渡逻辑。
- 调整 `OrbitControls` 鼠标映射，删除普通滚轮的时间轴截获和中心左键展开候选判断。
- 新增视口预设控件、Blender 导航说明和移动端适配；更新 README 交互文档。

## 验证

- `node --check src/main.js` 通过。
- `npm run build` 通过，仅保留既有 Three.js 大于 500 kB 的构建提示。
- `git diff --check` 通过，仅有 Git 行尾转换提示。
- 本地浏览器分别检查透视总览、前视和当前帧构图；透视状态可见完整 91 层空间体，当前帧状态不再发生全层透明叠糊。

## 结果

视口现在把时间切片作为固定三维对象操控；用户相机不再被动画循环拉回，空间旋转、平移和缩放与时间播放各自拥有独立输入通道。

## 遗留与下一步

- 仍需在真实三键鼠标、Windows 触控板和移动触摸设备上复核输入手感。
- 中低端 GPU 的 91 张透明纹理排序和显存表现仍需部署环境验证。

## 待确认长期记忆

- Blender 风格输入映射、双枢轴视口和深度测试属于后续实现必须遵守的视口契约。
