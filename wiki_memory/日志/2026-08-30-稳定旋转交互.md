# 2026-08-30｜稳定旋转交互

## 目标与结果

用户反馈原旋转机制容易眩晕。本次将“展开、主体旋转、切片组旋转、相机绕行”拆开，改为固定相机的单一转台；横向拖拽仍可连续旋转 360°及更多圈，但旋转反馈更可预测。

## 已确认的决策

- “展开切片”按钮独立控制展开，拖拽不再改变 `spreadTarget`。
- 横向拖拽累积不封顶的 `yawTarget`，纵向拖拽只调整 ±28° 的 `pitchTarget`。
- 拖拽超过约 8px 后按主方向锁定，斜向手势不会同时改变两个角度。
- 兰花和 76 张切片统一挂在 `rotationRig` 下，相机固定，不再随视角移动。
- 移除滚动后段自动绕行和松手惯性；保留低幅度环境动效，reduced-motion 下关闭持续环境动态。

## 检查与操作范围

- 检查了 `src/main.js` 的旋转状态、Pointer Events、键盘控制、相机更新和环境动效。
- 检查了 `index.html` 操作提示与 `README.md` 交互说明。
- 同步更新 `PROJECT_MEMORY.md`、当前状态、模块知识和 ADR-003；新增 ADR-005。
- 未重新导出 Blender 模型、GLB 或 76 张 PNG。

## 文件变更

- `src/main.js`：新增固定相机转台、yaw/pitch 方向锁定和独立展开控制。
- `index.html`、`README.md`：更新拖拽、按钮、键盘和滚动提示。
- `PROJECT_MEMORY.md`、`wiki_memory/`：同步长期决策、知识、状态和本次日志。

## 测试与验证

- `npm run build`：通过；Vite 仅提示 Three.js 产物超过 500 kB 的既有体积警告。
- `git diff --check`：通过。
- 本地 HTTP：页面、`flower.glb`、`slice-manifest.json` 和 `frame-001.png` 至 `frame-076.png` 均为 HTTP 200，缺帧数为 0。
- 代码级交互检查：固定相机、统一转台、无自动相机绕行、8px 方向锁定、±28°俯仰和 reduced-motion 保护均通过。
- Chrome 无头读取页面成功，但无头 WebGL 未完成模型载入；真实 Chrome、Edge、Safari 和移动设备体感仍需继续验证。
