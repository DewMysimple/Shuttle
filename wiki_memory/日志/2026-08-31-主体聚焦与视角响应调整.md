# 2026-08-31｜主体聚焦与视角响应调整

- 时间：2026-08-31（北京时间）
- 类型：`ui`
- 状态：`完成`
- 目标：让最大缩放达到参考图的主体聚焦距离，并提高俯仰、视角旋转与缩放的响应速度。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的决策

- `CAMERA_MIN_DISTANCE` 从 `5.2` 调整为 `3`；滚轮最大放大时相机更接近当前时间切片中心，主体视觉尺寸明显增加。
- `CAMERA_ZOOM_SENSITIVITY` / `CAMERA_ZOOM_SMOOTHING` 调整为 `0.011` / `11`，放大和缩小更快，同时保留可打断阻尼。
- `YAW_PER_VIEWPORT` 调整为 `1.85π`，每个视口宽度约旋转 333°；拖拽/释放旋转阻尼调整为 `14` / `8`。
- `PITCH_PER_VIEWPORT` 调整为每个视口高度约 100°，`PITCH_LIMIT` 扩大到 ±45°；屏幕向下拖动仍为俯视，向上拖动仍为仰视，边界不会翻转。
- 播放、当前时间切片聚焦、切片布局和 PNG 资产不变；不重新导出 Blender。

## 理由

- 参考图的主体占据更明确的视觉焦点，原 `5.2` 的最近距离不足；`3` 提供本轮要求的最大近景范围。
- 俯仰仅扩大到 ±45°，增加观察自由度但仍远离翻身区域；更快响应通过灵敏度和阻尼共同调整，保持连续控制。
