# 2026-09-02｜恢复原生三维控制

## 目标

修复真实水平时间切片重构后相机失去原生三维操作的问题，同时保留实体平面穿梭和径向展开的交互语义。

## 确认的原因

旧实现的 `updateTimeline()` 每帧直接覆盖相机位置、朝向和 `lookAt`；画布左键也被全部交给自定义径向拖拽，因此没有 Three.js 原生轨道控制的有效入口。

## 实施

- 在 `src/main.js` 接入 Three.js `OrbitControls`。
- 原生控制恢复为左键旋转、右键平移、中键缩放；时间滚轮在捕获阶段被截获为逐帧穿梭。
- 自动相机只在 `cameraMode: auto` 下驱动；用户启动原生控制后只跟随时间轴的 Y 位移，不再覆盖 X/Z 方向和观察角度。
- 中心区域左键径向拖拽继续负责展开/收拢，`Alt + 左键` 可从任意位置强制进入展开手势；增加可见的 `3D` 复位按钮并保留 `R` 快捷键。
- 更新画布无障碍文案、README、当前状态、ADR-016 和 Three.js 交互知识页。

## 验证

- `node --check src/main.js` 通过。
- `npm run build` 通过；Three.js 主包体积警告仍为既有构建提示。
- `git diff --check` 通过。
- 本地 Vite 桌面截图确认 91 张逐帧资产载入，展开总览与新 3D 复位按钮可见。

## 待确认长期记忆

- 原生相机控制与时间轴穿梭必须保持输入分流：普通滚轮属于时间，OrbitControls 属于鼠标三维操作。
