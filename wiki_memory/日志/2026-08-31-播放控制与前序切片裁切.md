# 2026-08-31｜播放控制与前序切片裁切

- 时间：2026-08-31（北京时间）
- 类型：`feature`
- 状态：`完成`
- 目标：播放推进到当前时间切片后，隐藏已经越过当前帧的历史切片；在主界面右侧增加一次点击即可使用的正放、倒放、开头和结尾控制；同步记录每次推送必须回报完整 commit hash 的工程约定。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的决策

- `currentFrameIndex = floor(frameFloat)` 作为可视门槛；当 `index < currentFrameIndex` 时，切片设为 `visible = false`，不再从相机前方形成历史叠加。倒放回到较早帧时，切片根据新的门槛重新显示。
- 右侧“正放”和“倒放”按钮直接调用既有方向播放状态；点击当前激活方向可暂停，点击另一方向切换播放方向。
- 右侧“开头”和“结尾”按钮会先暂停，然后将 `frameFloat` 定位到 `0` 或 `sliceCount - 1`，并更新状态文案。
- 播放按钮保持独立的激活态、`aria-pressed` 和至少 44px 的触控高度；按压使用轻微 `scale(0.96)`，不引入第二套样式系统。
- 根目录 `AGENTS.md` 明确规定：每次提交并推送后，聊天回复必须报告完整 40 位 commit hash、commit message、`origin/main` 和工作区状态。

## 实施内容

- 更新 `src/main.js`：增加播放/跳转按钮引用、播放按钮状态同步、边界跳转函数，并在切片更新时裁切当前帧之前的切片。
- 更新 `index.html`：在舞台右侧加入四个控制按钮。
- 更新 `src/style.css`：加入半透明纵向控制组、激活态、键盘焦点态、按压反馈和移动端位置适配。
- 更新 `README.md`、`PROJECT_MEMORY.md`、`AGENTS.md` 以及 `wiki_memory` 当前状态、知识页和 ADR-009。
