# 纵深光晕与播放层次修复

## 目标

回应播放重构后“主体变自然了，但纵深穿越感变弱”的反馈。参考 MP4 只作为视觉参考，不引入其素材、文字或新的滚动时间控制；保留中心主体稳定、按钮/长按播放、滚轮缩放和拖拽旋转。

## 分析结论

- 参考效果不是单靠更亮的主体光晕，而是由中心主体光晕、固定时间隧道、沿深度移动的低透明度时间位置、方向性残影共同构成。
- 当前版本的主光晕只覆盖 `focusLayer`，播放期间固定时间轴透明度被压到约 22%，残影只有很小的横向偏移，因此纵深线索被压平。
- 不恢复 `frameFloat` 驱动的整组 Z 轴平移；那会让规则矩形卡片重新高速扫过镜头，并破坏主体稳定性。

## 确认的决策

- 保持 166 张切片以时间中点为固定 Z 轴空间结构；播放期间新增低透明度 `playbackCursor`，按当前 `frameFloat` 在固定切片中形成连续衰减的时间游标，让空间中的焦点从前向后穿过，而不是移动整组切片。
- 播放时提高时间轴结构的可读性但保留降噪：`timelineVisibility` 从完全压低改为约 `0.74 → 0.52` 的静态到播放范围；游标只额外增强附近切片的轮廓、图像、暖色和微光。
- 主焦点暖珊瑚光晕从 `0.074 ± 0.018` 提高为 `0.108 ± 0.024`；播放中的背景环线和环境 halo 仅做低幅增益，不把整页改成白色雾层。
- `playbackTrail` 继续最多 5 层，保留方向性横向偏移，并增加 `0.085` 的 Z 轴深度步进和更明显的尺度衰减，正放与倒放都沿相反方向产生空间残影。
- 不修改 PNG、manifest、`flower.glb`、Blender 源文件和导出脚本。

## 文件变更

- `src/main.js`：增强中心焦点/环境光晕，加入固定时间隧道中的播放游标，扩大残影的横深间距。
- `wiki_memory/`：同步播放运动层级和光晕职责，新增本日志。

## 测试摘要

- `node --check src/main.js`、`npm run build`、`git diff --check` 通过；构建仅保留既有的 Three.js bundle 体积提示。
- 本地 Vite 资源回归通过，入口、manifest 和全部 166 张 PNG 均返回 HTTP 200。
- 浏览器自动化环境不可用，未完成真实 Chrome/Edge 中的逐帧 10% 速度视觉验收；需重点确认展开/收拢、正放/倒放、侧面旋转和 reduced-motion 下的光晕强度。

## 结果

播放表现改为“中心主焦点稳定 + 固定时间隧道可见 + 低透明度时间游标穿越 + 横深残影 + 局部光晕”。这保留了自然姿态交叉淡化，也补回参考效果中的空间通道感；光晕被作为空间分层的辅助信号，而不是单独用亮度掩盖切片感。
