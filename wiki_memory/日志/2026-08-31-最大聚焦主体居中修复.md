# 最大聚焦主体居中修复

## 目标

修复滚轮放大到最近距离时兰花主体持续落在画面下方的问题，让最大聚焦状态下的主体回到视觉中心附近，同时保留既有缩放、旋转、播放和时间轴结构。

## 诊断

- 当前 PNG 主体位于透明画布中心附近，问题主要来自相机目标高度：`cameraFocusPoint` 与初始 `camera.lookAt()` 使用 `y = 0.5`，而中心 `focusLayer` 位于接近 `y = 0` 的焦点平面。
- 相机在最近距离 `3` 时视野更紧，这个约 `0.5` 世界单位的目标偏移被放大成明显的屏幕下移，因此不是优先修改原始材质或重新导出 PNG。

## 确认的决策

- 新增 `CAMERA_FOCUS_Y = 0.04`，让动态相机目标对准主焦点所在平面附近，并同步修改初始相机 lookAt。
- 新增 `CAMERA_EYE_HEIGHT_OFFSET = 0.75`，让相机眼睛与目标保持原有相对高度差，避免修正垂直构图时改变透视手感。
- 保留 `cameraZoom` 的 `3–15.5` 边界、阻尼、滚轮职责、拖拽旋转、播放和时间切片位置；不移动 PNG，不修改 GLB、Blender 源材质或导出脚本。

## 文件变更

- `src/main.js`：校正初始相机目标、动态焦点目标和相机眼睛高度。
- `wiki_memory/当前状态/项目概览.md`、`系统架构.md`、`当前约束.md`、`当前待办.md`：同步相机焦点高度和当前构图边界。
- `wiki_memory/决策/ADR-009-长按播放与滚轮缩放.md`：补充滚轮缩放的视觉中心与相机高度规则。
- `PROJECT_MEMORY.md`、`README.md`：记录主体中心稳定性要求。

## 测试摘要

- `node --check src/main.js`、`npm run build`、`git diff --check` 通过；构建仅保留既有的 Three.js bundle 体积提示。
- `memory_lint.py index`、`memory_lint.py check` 通过；本地 Vite 资源回归通过，入口、manifest 和 166 张 PNG 均返回 HTTP 200；静态检查确认已移除旧的 `camera.lookAt(0, 0.5, 0)`。
- 当前环境没有可用的浏览器自动化入口，最大缩放状态仍需在真实 Chrome/Edge 中视觉确认。

## 结果

相机焦点已从偏高目标改为贴近主体焦点平面的光学中心，并保持原眼睛高度差；最大放大时主体不再因相机 lookAt 偏移而持续落到画面下方。
