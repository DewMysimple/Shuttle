# 2026-08-30｜时间隧道切片优化

- 时间：2026-08-30（北京时间）
- 类型：`ui`
- 状态：`完成`
- 目标：将透明切片叠加优化为当前帧中心锚定的 X/Z 空间时间隧道，并提升主体可读性。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的决策

- 当前帧使用 `index - frameFloat` 计算相对位置，滚动时保持在正面视觉中心。
- 采用稳定的 X/Z 时间轨迹，不使用螺旋或自动镜头绕行；首屏保持展开状态。
- 当前帧清晰高饱和，近帧保留重影，中远帧分级淡化；侧视适度提高尾部可见度。
- 使用网页端 shader 色彩增强和较低的白色 screen 雾层，不修改 PNG，不恢复实时 GLB 模型。

## 检查与操作

- 比较了原固定时间中点叠放与参考图的正面隧道、侧面时间梳子差异。
- 调整 `src/main.js` 的切片尺寸、X/Z 间距、焦点透明度层级、侧视可见度和运行时色彩等级。
- 调整 `src/style.css` 的白色 screen 雾层覆盖度，并更新 README 与 `PROJECT_MEMORY.md`。
- 新增 ADR-007，补充当前状态页、Three.js 模块页和主界面动效页。
