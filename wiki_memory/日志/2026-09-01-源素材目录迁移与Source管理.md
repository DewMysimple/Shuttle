# 源素材目录迁移与 Source 管理

## 目标

将蝴蝶 `.blend` 和两段参考 MP4 从外层 `Free/` 根目录收纳到项目根目录的 `Source/`，让 `Shuttle/` 成为唯一网页工程管理根目录，同时不把外部源素材提交到 Git。

## 确认的决策

- 项目 Git 根目录为 `Shuttle/`，不再使用独立的 `rhododendron-time-slices/` 子目录。
- `Source/` 作为本地源素材目录，保留三个文件；除 `Source/README.md` 外全部由 `.gitignore` 排除。
- `public/assets/` 继续只保存网页运行所需的 91 张蝴蝶 PNG、清单和历史检查资产。

## 检查范围

- 核对三个源文件的实际完整文件名和文件大小。
- 确认 `Shuttle/Source/` 目标目录从空目录创建，移动后 `Free/` 根目录不再保留三个文件。
- 确认 `Shuttle/` 根目录直接包含 `.git`，工作树和 `origin/main` 关系不受影响。

## 变更与结果

- 移动 `BUTTERFLY_FLAP_FAST_FOLLOW_PATH_1.blend` 和两段参考 MP4 到 `Source/`。
- 更新 `.gitignore`、项目 README、长期工程记忆和本日志，说明 Source 与运行资产的边界。
- 未删除任何源文件；只移除了迁移后的空旧目录内容位置，`Free/` 下其他素材保持不动。

## 遗留问题

- `Source/` 中的本地大文件不会随 Git clone 自动出现；换机器时需手动准备源素材，或从备份恢复。
