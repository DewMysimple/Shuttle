# 本地运行与部署

## 一句话结论

网页运行只需要 Node 依赖和 `public/assets/` 下的生成资产，重新导出模型时才需要 Blender 与外部 Alembic 缓存。

## 适用范围

本地开发、生产构建、静态部署和资源缺失排查。

## 详细内容

```powershell
npm install
npm run dev
npm run build
npm run preview
```

生产部署托管 `dist/`，并确认 `flower.glb`、`slice-manifest.json` 和 `slices/frame-001.png` 至 `frame-076.png` 都被打包或可访问。更换模型时运行 `scripts/export_blender_assets.py`，需要同时提供 Blender 源文件和外部 ABC 缓存。

## 常见问题或陷阱

- 页面加载显示“资源缺失”时，先检查 Vite 根目录和 `public/assets/`，再检查导出资产是否存在。
- Alembic 缓存不是网页运行依赖，不应复制进部署目录。
- 部署后优先检查根页面、GLB、manifest 和所有 PNG 的 200 状态。
