# 开发与验收

## 固定流程

1. 读取 `wiki_memory/AGENTS.md`、当前状态和相关决策/知识页。
2. 修改代码或资产；实质任务新增日志并同步长期记忆。
3. 运行 Python/JavaScript 语法检查和 `npm run build`。
4. 验证 manifest、91 张 PNG 的数量/尺寸/模式/源帧连续性；静态检查不存在中心纹理替换。
5. 浏览器截图至少覆盖收拢正视、展开水平分层和侧视结构；确认没有额外中心框。
6. 运行 `python wiki_memory/工具/memory_lint.py index` 与 `check`。
7. 运行 `git diff --check`，检查工作区后提交并推送 `origin/main`。

## 资产验收基线

- `frame-001.png` 到 `frame-091.png` 全部存在、为 768×768 RGBA，manifest 源帧连续 1 到 91。
- manifest 必须声明 `fixed-top-front`、`xz-horizontal` 和 Y 轴时间序列。
- `src/main.js` 不得出现 `focusLayer`、`focusTrail` 或运行时 `.map =`。
