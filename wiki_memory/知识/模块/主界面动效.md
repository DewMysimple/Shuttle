# 主界面动效

## 一句话结论

主界面用克制的粉彩空间、轻粒子和结构性相机运动突出蓝色蝴蝶；动效必须解释时间平面，不得添加与真实切片混淆的框体。

## 当前规则

- CSS 使用珊瑚、奶油和淡紫的单一浅色主题，中心留出暖色视觉焦点；蓝色仅由蝴蝶主体提供。
- Three.js 环境只保留低透明度粒子与两层无边框光晕，不创建轨道环、门户框或中心装饰框。
- 当前帧不通过额外发光代理增强；其清晰度来自真实平面的最高透明度和自身边界。
- 展开动效同时增加 Y 轴层间距、退远相机并提高斜侧倾角，使平行水平面结构可读。
- `prefers-reduced-motion` 下阻尼立即到达目标，关闭背景持续运动和呼吸缩放，但保留用户触发的穿梭与展开。

## 常见陷阱

- 不要使用大量白色 screen 雾覆盖蓝色翅膀。
- 不要用额外矩形强调当前帧；它会被误读为第 92 个切片。
- 不要让展开后的平面在同一投影立面互相穿插；优先从斜侧展示真实层间距。
