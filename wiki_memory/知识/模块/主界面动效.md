# 主界面动效

## 一句话结论

主界面动效由 CSS 背景层、Three.js 内容层和交互反馈层组成，形成持续但可控的空间氛围。

## 适用范围

新增或调整漂浮、粒子、光环、光晕、镜头微动、切片动态和 reduced-motion 行为时参考本页。

## 详细内容

- CSS `haze-drift` 和 `veil-breathe` 让背景渐变与雾光持续流动。
- 时间切片组沿 Y 轴轻微呼吸漂浮，但单张切片不再添加位置或角度扰动，避免破坏平行关系。
- 166 张切片空间以固定 `timelineCenter` 为中心：全部切片保持正面平行，沿世界 Z 轴以 `1` 步进形成等距深度序列；不使用 X 轴共面堆叠、X/Z 曲线、逐片倾斜或曲线微动，整体 `sliceRoot` 呼吸仍可保留而不改变卡片之间的平行与间距。播放时由独立 `focusLayer` 在视觉中心交叉淡化当前/下一帧，历史帧不会因播放进度被隐藏；收拢时以当前四舍五入帧作为唯一清晰主体。
- 透明度按焦点分级：当前帧约 `0.96`，相邻帧约 `0.16–0.30`，中距离帧约 `0.06–0.14`，远处切片约 `0.02–0.06`；焦点帧同时获得更高的运行时饱和度和对比度，避免 166 张 PNG 叠加成白雾。
- 当前帧增加透明纹理加法混合副层，使用约 `3.8%–6.6%` 的暖粉色轮廓微光；微光按连续 `frameFloat` 权重交接，并以约 `1.7s` 周期呼吸，`prefers-reduced-motion` 下保持静态。
- 环境层包含桌面端 64 个粒子、3 层轨道光环和 2 层呼吸光晕；移动端减少数量和几何细节。
- 相机保持固定；时间切片由统一转台响应用户旋转，环境层只保留低幅度独立动效，避免叠加视差造成眩晕。
- 旋转使用更快的无惯性可打断阻尼：拖拽过程中用 18 跟随，释放后用 10 短暂收敛；双轴输入不改变环境层的独立动效节奏。
- 长按播放是明确的用户触发动效：左键正向、右键倒放，松开立即停止，播放期间可继续旋转；滚轮缩放使用可打断阻尼，以视觉中心主焦点为焦点，不把相机缩放叠加到环境层或时间切片的时间状态；相机使用 `CAMERA_FOCUS_Y = 0.04` 避免最大放大时主体下坠。

## 常见问题或陷阱

- 动效必须服务于时间切片，不要让环境层遮盖兰花或降低当前帧可读性。
- 白色 screen 雾层只能作为背景氛围，不能覆盖主体色彩；调整雾光后要复查正面主体和侧面切片轮廓。
- 新增持续动画时必须同步处理 `prefers-reduced-motion`。
- 检查移动端 GPU 开销，不要默认把桌面端粒子数量带到小屏设备。
