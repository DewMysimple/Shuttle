# ADR-003｜单界面交互与动效方向

## 状态

`active`

## 背景

用户要求只保留参考图对应的主界面，并进一步要求视角可以自由 360° 旋转、动效丰富。页面需要让主体、时间切片和环境层同时有变化，但不能牺牲时间轴播放的清晰度。

## 决策

使用单一全屏主舞台。长按播放完整时间切片状态，滚轮独立控制主体缩放，展开按钮独立控制时间切片，拖拽只控制固定相机转台的视角；横向累积不封顶的方位角，纵向控制 ±28° 的轻微俯仰。页面只呈现透明时间切片，不再显示中央实时模型。继续保留切片漂移、粒子、轨道光环、光晕和 CSS 雾光流动，但不以 Apple Design 的弱化动效取向作为本项目约束；`prefers-reduced-motion` 仅作为无障碍兜底。

## 理由

- 单一舞台能把注意力集中在兰花和时间轴上。
- 不封顶的方位角可以连续旋转完整 360° 及更多圈。
- 固定相机与统一转台能保留空间感，同时避免主体、相机和切片组多层叠加导致眩晕。
- 多层低幅度环境动效能让页面持续有生命感，但不再跟随用户视角明显转动。

## 影响

- 正面影响：作品更接近参考视频的时间切片视觉，首屏只聚焦时间轨迹，且不需要加载中央实时模型。
- 代价或风险：视角内容完全由 166 张预渲染切片决定；持续动效增加 GPU 和 CPU 开销，必须保留移动端降级与 reduced-motion 分支。

## 验证方式

- 首屏只存在一个主 section。
- 画布横向拖拽可连续旋转 360°，纵向可在 ±28° 内调整俯仰，方向锁定后斜向手势不同时改变两轴，展开按钮不重置视角。
- 固定相机不随用户方位角移动，长按播放和滚轮缩放不触发自动镜头绕行。
- reduced-motion 环境下持续动效被关闭或显著降低。
