# ADR-003｜单界面交互与动效方向

## 状态

`active`

## 背景

用户要求只保留参考图对应的主界面，并进一步要求视角可以自由 360° 旋转、动效丰富。页面需要让主体、时间切片和环境层同时有变化，但不能牺牲滚动时间轴的清晰度。

## 决策

使用单一 sticky 主舞台。滚动控制时间，横向拖拽同时控制切片展开和不封顶的方位角，纵向拖拽控制俯仰角；加入主体呼吸漂浮、切片漂移、粒子、轨道光环、光晕、镜头微动和 CSS 雾光流动。不以 Apple Design 的弱化动效取向作为本项目约束，但保留 `prefers-reduced-motion` 无障碍兜底。

## 理由

- 单一舞台能把注意力集中在兰花和时间轴上。
- 不封顶的方位角可以连续旋转完整 360° 及更多圈。
- 多层低幅度动效能让页面持续有生命感，同时不改变滚动与拖拽的核心映射。

## 影响

- 正面影响：作品更接近参考视频的沉浸式空间体验，用户始终处于同一个交互上下文。
- 代价或风险：持续动效增加 GPU 和 CPU 开销，必须保留移动端降级与 reduced-motion 分支。

## 验证方式

- 首屏只存在一个主 section。
- 画布横向拖拽可连续旋转 360°，纵向可调整俯仰，展开按钮不重置视角。
- reduced-motion 环境下持续动效被关闭或显著降低。
