# ADR-017｜Blender 式三维视口与时间输入解耦

## 状态

`active`

## 背景

第一次恢复 `OrbitControls` 后，相机仍由时间轴 `focusY` 和自动总览逻辑驱动，中心左键还可能被展开手势接管。切片材质统一关闭深度测试，并按时间距离强制渲染顺序，因此即使发生相机旋转，观看感受仍接近一组扁平透明图层，而不是可检查的三维切片体。

## 决策

- 使用 `PerspectiveCamera` 和 `OrbitControls` 建立独立视口；中键旋转、`Shift + 中键` 平移、滚轮缩放，并保留左键旋转与右键平移作为网页和触控板兼容入口。
- 普通滚轮完整交给视口缩放；`Alt + 滚轮` 逐帧穿梭，`Alt + Shift + 滚轮` 一次移动五帧。
- `Alt + 左键` 径向拖拽改变切片层距；普通左键不再被中心区域手势拦截。
- 默认从中位第 46 帧进入展开的透视总览，枢轴固定在 91 层包围体中心。时间切换只改变选中实体平面，不改写自由相机。
- 当前帧预设将枢轴切到所选平面并沿 Y 轴跟随，因此仍可通过经过真实实体层实现逐帧穿梭；其余预设保持整组包围体枢轴。
- 提供透视、前视、侧视和当前帧预设，并按实时包围体尺寸计算相机距离。`Home`/`R` 框显全部，数字键盘 `1`/`3`/`7` 对应前视、侧视和当前帧。
- 所有真实切片重新启用深度测试并取消按时间距离强制渲染顺序；斜视状态显示轻量地面网格，俯视当前帧时自动隐藏网格。

## 理由

- 独立的固定枢轴使相机操作围绕三维对象发生，而不是围绕不断移动的当前纹理平面发生。
- 输入通道分离后，视口缩放、空间旋转、帧穿梭和层距展开不会互相抢占。
- 深度测试和空间参照让相邻平面的遮挡、间距和透视缩短真实反映相机方位。
- 当前帧预设保留固定正视构图，总览预设负责检查完整空间结构，两种任务不再由一个自动相机折中完成。

## 影响

- ADR-016 中“普通滚轮逐帧、修饰键滚轮缩放”和“展开时自动相机斜侧总览”的交互条款由本决策取代；ADR-016 的真实逐帧、水平平面和固定纹理契约继续有效。
- 首屏从收拢正视改为展开透视，用户可立即感知完整三维切片体；仍可通过按钮、`E` 或径向拖拽收拢。
- 前视与侧视用于检查平行关系，当前帧预设用于观察蝴蝶图像，不应把前视/侧视误当作单帧播放器。

## 验证方式

- 静态检查 `OrbitControls` 的中键旋转、右键平移和滚轮缩放映射，确认普通滚轮监听不会 `preventDefault`。
- 检查动画循环只按枢轴变化平移相机，不再根据当前帧无条件重建相机位置和 `lookAt`。
- 浏览器检查透视总览、前视、侧视和当前帧；旋转后相机结果必须保持，当前帧必须维持固定蝴蝶构图。
- 运行语法检查、Vite 生产构建、差异检查和记忆 lint。
