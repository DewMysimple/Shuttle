# ADR-013｜全帧可见与扩大俯仰范围

## 状态

`active`

## 背景

上一版为了避免已越过的切片回到相机前方，按播放进度隐藏当前帧之前的历史切片；这会削弱完整时间轨迹，也与用户希望持续观察前后时间状态的效果不一致。同时，±45° 的俯仰范围不足以自由观察平行切片的上下两侧。

## 决策

- 继续使用 `offset = index - state.frameFloat`，让当前时间切片保持在焦点原点。
- 所有 166 张切片始终设置为可见；历史、当前和未来切片都参与位置、透明度和颜色分级，不再按播放进度裁切历史帧。
- 保持切片正面平行，沿世界 Z 轴等距分层，`SLICE_DEPTH_STEP = 0.62`；位置为 `x = 0`、`y = 0`、`z = -offset × 0.62 × spread`。
- 俯仰 `pitchTarget` 的边界改为 ±90°；屏幕向下拖动增加俯视角，向上拖动减少俯视角，水平方向仍独立累积不封顶 yaw；斜向拖动同时消费两个轴的增量。
- 保留固定相机、统一 `rotationRig`、无惯性短阻尼、长按播放期间可旋转、滚轮以当前时间切片为焦点缩放和丰富环境动效。

## 理由

- 全帧保留能让时间切片序列成为连续的完整空间记录，而不是随播放逐步消失的单向队列。
- 增大的深度步进让相邻平行卡片在侧视和斜视时更容易辨认，不会因间距过小而合并成一张面。
- ±90° 提供完整上下观察范围，同时仍以边界限制避免继续越界造成不可控翻转；平滑跟随保留操作连续性。

## 影响

- 播放到中后段时，之前的切片仍会保留在相机前侧，并由距离透明度衰减；完整时间轨迹的前景叠加会比裁切方案更丰富。
- 166 张切片的最大深度跨度增加，远端切片可能落在相机视锥之外，但不会被逻辑删除；旋转或缩小镜头时仍可重新进入视野。
- 俯仰到 ±90° 时会进入接近极点的观察姿态；这是明确的自由视角边界，不应继续扩大为超过 ±90°。

## 验证方式

- 静态检查 `PITCH_LIMIT` 为 `THREE.MathUtils.degToRad(90)`、`SLICE_DEPTH_STEP` 为 `0.62`、`slice.visible = true` 且不存在播放历史裁切分支。
- 运行 `node --check src/main.js`、`npm run build`、`git diff --check`、`memory_lint.py index` 和 `memory_lint.py check`。
- 浏览器复核首帧、中段和尾帧的完整切片可见性、正面/侧面间距、上下 ±90° 视角与播放期间旋转；未执行的手动检查必须在工作日志中明确记录。
