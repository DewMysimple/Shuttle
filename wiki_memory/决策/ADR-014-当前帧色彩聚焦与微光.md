# ADR-014｜当前帧色彩聚焦与微光

## 状态

`active`

## 背景

时间切片展开后，如果所有 PNG 使用接近的透明度，多个浅色兰花姿态会叠加成白雾，播放中的当前帧也不够突出。现有卡片边缘可以保留时间序列，但不能承担主体焦点的全部反馈。

## 决策

- 独立 `focusLayer` 固定在视觉中心，使用当前帧和下一帧纹理按 `frameFloat` 小数部分连续交叉淡化；焦点图像最高约为 `0.99`，播放时最多增加 5 层低透明度 `playbackTrail`，不为残影创建卡片边框。
- 固定时间轴切片不再跟随 `frameFloat` 沿 Z 轴整体移动；其卡片、轮廓和远端图像在播放期间整体降噪，但保留低透明度 `playbackCursor` 沿固定深度序列连续穿过，避免规则矩形高速扫过镜头同时保留空间通道感。
- 主焦点使用约 `1.04–1.90` 的连续饱和度分级、最高约 `1.29` 的对比度、低强度暖珊瑚色偏移、轻微尺度提升和 `0.108 ± 0.024` 的局部加法微光；环境环线和 halo 仅在播放时做低幅局部增益，其他帧不增加同等高光。
- 主焦点、固定时间游标和有限横深残影共同承担运动信噪比；背景白色 screen 雾层和 haze 呼吸保持低覆盖度，并在主体背后保留低强度深玫红对比区。
- 焦点权重使用 `frameFloat` 的连续小数部分，播放时相邻整数帧平滑交接；普通模式下微光周期约 `1.7s`，`prefers-reduced-motion` 下关闭残影漂移和微光呼吸，只保留稳定焦点与帧间交叉淡化。
- 收拢状态继续由主焦点层显示 `Math.round(frameFloat)` 对应时间状态；不增加后处理 Bloom，也不修改运行资产或新增滚动时间控制。

## 理由

- 固定时间轴、独立焦点层和低透明度时间游标分责后，空间序列不再制造高速卡片运动，主体姿态变化与游标穿越共同成为播放中的运动信号。
- 当前/下一帧交叉淡化和有限轨迹残影比同时提高整组切片透明度更容易维持清晰焦点，减少浅色主体叠加造成的泛白。
- 独立副层、局部暖色偏移、横深残影和对比背景比提高整张图亮度更容易控制，能够让焦点有“被照亮”的感觉并恢复空间层级，同时不破坏兰花原始色彩。

## 影响

- 正面观察时当前兰花更鲜艳、更稳定，播放轨迹由有限残影补充，时间轴仍由低透明度的固定卡片、边缘和远端图像保留。
- 收拢时仍只显示当前时间焦点；展开时恢复固定的历史、当前和未来切片层级。
- 增加两个焦点交叉层和 5 个低透明度残影平面，桌面端开销小幅增加；不增加额外图片请求，移动端仍沿用现有 DPR 和粒子降级策略。

## 验证方式

- 检查当前帧、相邻帧、中距离帧和远距离帧的透明度常量、运行时色彩分级、暖珊瑚偏移和背景雾层。
- 运行 `node --check src/main.js`、`npm run build`、`git diff --check`、`memory_lint.py index` 和 `memory_lint.py check`。
- 浏览器复核首帧、中段、尾帧、播放连续过渡、收拢态和 `prefers-reduced-motion`；确认主体没有再次被白雾覆盖。
