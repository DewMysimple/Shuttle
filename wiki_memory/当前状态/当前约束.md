# 当前约束

> 记录 Agent 修改项目时必须遵守的限制。没有依据的内容不要写入。

## 技术约束

- 主体必须保持为兰花；准确源文件名为 `兰花_形态1.blend`。
- 源动画依赖外部 Alembic 缓存；运行仓库只提交导出的 GLB、166 张 PNG 和清单。
- 不重新加入棕色展示台，不把参考 MP4 或外层原始素材纳入仓库。
- 主界面不显示或加载中央实时 3D 模型，只保留 166 张透明时间切片；`flower.glb` 仅作为可选导出检查资产。
- 前端使用 Three.js/Vite，页面保持单一主界面。
- 视角使用固定相机的单一 `rotationRig`；交互旋转不再叠加相机绕行和切片组独立绕行。
- 旋转输入保留双轴独立语义：水平位移只改变 yaw，垂直位移只改变 pitch，斜向位移同时生效；俯仰范围为 ±45°，并维持下拖俯视、上拖仰视，不能突破边界翻转。
- 时间切片必须以 `offset = index - frameFloat` 相对当前帧布局；当前可见切片保持正面平行，沿世界 Z 轴以 `SLICE_DEPTH_STEP = 0.42` 等距分层，禁止共面、相交、横向错位或退回到 X+Z 曲线/隧道轨迹。
- 当前源动画的每个整数帧都必须有对应切片，manifest 与 PNG 数量必须一致；当前范围为 1–166，共 166 帧。
- 时间控制必须使用长按播放、松开暂停；左键长按正向、右键长按倒放；页面滚动不再改变 `frameFloat`。
- 播放和视角是独立状态；长按播放期间仍允许双轴拖拽旋转，不能用播放状态屏蔽视角更新。
- 滚轮只允许改变相机距离，必须保留平滑缩放边界（当前为 3–15.5）和更快的可打断响应，不得串改播放帧或 yaw/pitch。
- 平行深度序列的基础卡片/图片尺寸为 `2.15 × 1.72` 与 `1.92 × 1.54`，展开步进为 Z 轴 `0.42`；切片 X/Y 坐标和自身旋转保持为 0，修改时必须检查正面嵌套、当前帧居中和侧面分离边缘。
- 右侧必须提供“正放”“倒放”“开头”“结尾”四个按钮；正放/倒放单击启动对应方向，再次点击当前方向暂停；开头/结尾单击后暂停并定位到首帧/尾帧。
- 播放推进到第 N 帧后，索引小于 `floor(frameFloat)` 的历史切片必须从渲染中隐藏；倒放回到较早帧时，符合当前门槛的切片可以重新可见。

## 兼容性约束

- 桌面端优先完整展示 3D 时间轴；移动端降低 DPR、粒子数量和环线细节。
- 画布为单屏主交互区，需使用 `touch-action: none` 保证触摸长按、拖拽和缩放手势不被浏览器默认手势抢占。
- `prefers-reduced-motion` 下关闭切片漂浮、环境动态和阻尼过渡；固定转台仍响应用户明确的旋转输入。

## 质量约束

- 每次代码、视觉、运行资产或记忆修改都必须更新结构化记忆、运行 lint、提交并推送 `origin/main`。
- Git 只管理网页工程，不提交 Blender、MP4、FBX、MAX、Alembic 和原始贴图目录。
- 任何重新导出必须检查 166 帧、GLB 动画和透明边缘；导出脚本必须先按全动画评估包围盒适配相机，确保首帧、中段和尾帧都位于安全画布区域。
- 主体突出优先于环境雾光：当前帧使用最高透明度、饱和度和对比度，远处切片分级淡化，不能让 166 张 PNG 叠加成白雾。

## 操作边界

- 外部 Alembic 缓存是重新导出的已知依赖；换机器时需重新提供。
