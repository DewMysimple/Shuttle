# 当前约束

> 记录 Agent 修改项目时必须遵守的限制。没有依据的内容不要写入。

## 技术约束

- 主体必须保持为蝴蝶；准确源文件名为 `BUTTERFLY_FLAP_FAST_FOLLOW_PATH_1.blend`。
- 蝴蝶运行资产由 Blender 脚本离线采样；运行仓库只提交 91 张 PNG 和清单，历史 `flower.glb` 仍不参与网页运行。
- 不重新加入棕色展示台，不把参考 MP4 或外层原始素材纳入仓库。
- 主界面不显示或加载中央实时 3D 模型，只保留 91 张透明时间切片；`flower.glb` 仅作为历史可选导出检查资产。
- 前端使用 Three.js/Vite，页面保持单一主界面。
- 视角使用固定相机的单一 `rotationRig`；交互旋转不再叠加相机绕行和切片组独立绕行。
- 旋转输入保留双轴独立语义：水平位移只改变 yaw，垂直位移只改变 pitch，斜向位移同时生效；当前横向响应约 `396°/视口`、纵向约 `120°/视口`，俯仰范围为 ±90°，并维持下拖俯视、上拖仰视，不能突破边界翻转。
- 时间轴切片必须以固定 `timelineCenter = (sliceCount - 1) / 2` 布局；全部切片保持正面平行，沿世界 Z 轴以 `SLICE_DEPTH_STEP = 1` 等距分层，禁止共面、相交、横向错位或退回到 X+Z 曲线/隧道轨迹。`frameFloat` 不得在播放期间推动整组切片沿 Z 轴高速移动；收拢时必须保留主焦点层当前时间切片可见，不能因整体 reveal 归零而空白。
- 当前源动画的每个整数帧都必须有对应切片，manifest 与 PNG 数量必须一致；当前范围为 1–91，共 91 帧。
- 时间控制必须使用长按播放、松开暂停；左键长按正向、右键长按倒放；页面滚动不再改变 `frameFloat`。
- 播放和视角是独立状态；长按播放期间仍允许双轴拖拽旋转，不能用播放状态屏蔽视角更新。
- 滚轮只允许改变相机距离，必须保留平滑缩放边界（当前为 3–15.5）和更快的可打断响应，不得串改播放帧或 yaw/pitch。
- 相机必须以主体所在的焦点平面为观察中心；当前 `CAMERA_FOCUS_Y = 0.04`，不得恢复到会把主体持续压向画面下方的 `0.5` 观察高度。调整时要保持相机眼睛与焦点的相对高度差，避免改变既有透视手感。
- 平行深度序列的基础卡片尺寸为 `2.15 × 1.72`，蝴蝶透明图片平面为 `1.68 × 1.68` 以保持正方形 PNG 不变形，展开步进为 Z 轴 `1`；切片 X/Y 坐标和自身旋转保持为 0，修改时必须检查正面嵌套、当前帧居中和侧面分离边缘。
- 右侧必须提供“正放”“倒放”“开头”“结尾”四个按钮；正放/倒放单击启动对应方向，再次点击当前方向暂停；开头/结尾单击后暂停并定位到首帧/尾帧。
- 播放推进到任意帧后，当前帧之前的历史切片必须继续可见，并与当前及未来切片共同参与距离透明度分级；不得按播放进度永久裁切历史帧。
- 播放必须使用固定视觉中心的 `focusLayer` 交叉淡化当前/下一帧，并可使用最多 5 层低透明度 `playbackTrail` 残影；播放期间降低卡片轮廓和时间轴结构透明度，暂停后残影平滑退出并恢复普通时间轴展示。
- 为保留纵深穿越感，播放可在固定 Z 轴时间轴上使用低透明度 `playbackCursor` 连续标记当前时间位置，并让残影同时具有横向与 Z 轴衰减；不得恢复 `frameFloat` 推动整组切片高速扫过镜头。主焦点光晕和环境 halo 只能局部增益，不能依赖整页提亮制造空间感。

## 兼容性约束

- 桌面端优先完整展示 3D 时间轴；移动端降低 DPR、粒子数量和环线细节。
- 画布为单屏主交互区，需使用 `touch-action: none` 保证触摸长按、拖拽和缩放手势不被浏览器默认手势抢占。
- `prefers-reduced-motion` 下关闭切片漂浮、残影漂移、环境动态和微光呼吸；主焦点仍保持静态高亮与连续帧交叉淡化，固定转台仍响应用户明确的旋转输入。

## 质量约束

- 每次代码、视觉、运行资产或记忆修改都必须更新结构化记忆、运行 lint、提交并推送 `origin/main`。
- Git 只管理网页工程，不提交 Blender、MP4、FBX、MAX、Alembic 和原始贴图目录。
- 任何重新导出必须检查 91 帧和透明边缘；导出脚本必须使用正面跟随相机，确保首帧、中段和尾帧都位于安全画布区域。
- 主体突出优先于环境雾光：当前帧约使用 `0.99` 图像透明度、最高约 `1.90` 饱和度和 `1.29` 对比度，并使用蓝色焦点微光、低强度暖色偏移；播放中的固定时间游标和环境 halo 只做局部低幅增强；相邻、中距离和远处切片分级淡化，不能让 91 张 PNG 叠加成白雾。
- 播放主体稳定优先于整组时间轴运动：`focusLayer` 保持在视觉中心，`frameFloat` 只推进时间焦点；不得新增滚轮驱动时间帧，也不得把参考视频误读为滚动播放器。

## 操作边界

- 外部 Alembic 缓存是重新导出的已知依赖；换机器时需重新提供。
