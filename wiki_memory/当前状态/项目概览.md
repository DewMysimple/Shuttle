# 项目概览

## 项目名称

蝴蝶时间切片

## 项目目标

制作一个单屏 Three.js/Vite 互动艺术作品：将指定蝴蝶 `.blend` 的 1 到 91 帧逐帧采样为独立透明图片，再把每张图片永久绑定到一个真实 Three.js 平面。体验者通过时间输入或播放按钮沿实体平面逐帧穿梭，通过径向拖拽把时间堆栈展开为互不相交的水平平面序列，并使用 Blender 风格视口自由检查完整三维结构。

## 当前阶段

真实逐帧资产、水平平面结构、穿梭播放、径向展开、Blender 式三维视口和粉彩舞台均已实现；下一阶段以真实设备性能与手感验证为主。

## 核心目录

| 路径 | 用途 |
| --- | --- |
| `src/` | Three.js 场景、时间穿梭、交互与样式 |
| `Source/` | 被 Git 忽略的 Blender 源文件与参考 MP4 |
| `public/assets/` | 91 张运行时 PNG 与逐帧清单 |
| `scripts/` | Blender 固定正视逐帧导出脚本 |
| `wiki_memory/` | 结构化工程记忆 |

## 重要入口

- `src/main.js`：91 个永久纹理平面、Y 轴时间堆栈、相机穿梭与交互。
- `scripts/export_butterfly_slices.py`：沿 Z 轴正对 X-Y 平面的固定正交采样。
- `public/assets/slice-manifest.json`：源帧、视角和网页展示平面的契约。
