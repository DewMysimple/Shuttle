# 项目概览

> 这是 Agent 每次工作首先需要理解的项目摘要。保持简短，只记录当前有效事实。

## 项目名称

兰花 · 3D 时间切片

## 项目目标

制作一个单一主界面的 Three.js/Vite 互动作品页：将兰花 1–166 帧动画逐帧渲染为透明时间切片，用长按或右侧按钮播放让中心焦点保持稳定并让全部帧沿世界 Z 轴以步进 `1` 平行分层；当前帧保持最高透明度、色彩分级和微弱呼吸微光，历史切片持续可见并按距离淡化；收拢时以当前时间切片为清晰基准；用滚轮以视觉中心为焦点缩放主体、按钮展开时间切片，并用固定相机转台提供更快但可控的 3D 视角旋转。

## 当前阶段

已完成核心实现、兰花完整帧时间切片资产、全动画安全构图、平行深度切片构图、丰富动效、播放方向控制、主体聚焦缩放、当前帧微光聚焦、快速视角响应、Git 远程管理和结构化工程记忆；当前网页不加载中央实时模型，后续以真实设备验证和部署为主。

## 主要用户或使用者

项目作者与访问作品页的体验者。

## 核心目录

| 路径 | 用途 |
| --- | --- |
| `src/` | Three.js 场景、时间轴、交互和样式 |
| `public/assets/` | 自包含 GLB、166 张透明 PNG 和清单 |
| `scripts/` | Blender Alembic 缓存到 GLB/PNG 的导出脚本 |
| `wiki_memory/` | 结构化工程记忆、决策、知识和日志 |

## 重要入口

- `index.html`：单一主界面入口。
- `runStart.cmd`：Windows 双击启动入口。
- `src/main.js`：Three.js 场景、长按播放、滚轮缩放、拖拽旋转和切片展开。
- `src/style.css`：粉彩舞台、雾光和 CSS 动效。
- `scripts/export_blender_assets.py`：重新生成运行资产。
