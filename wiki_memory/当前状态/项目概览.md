# 项目概览

> 这是 Agent 每次工作首先需要理解的项目摘要。保持简短，只记录当前有效事实。

## 项目名称

兰花 · 3D 时间切片

## 项目目标

制作一个单一主界面的 Three.js/Vite 互动作品页：将兰花 1–166 帧动画逐帧渲染为透明时间切片，用滚动让当前帧锚定中心并让前后帧沿 X/Z 轴形成时间隧道，用按钮展开时间切片，并用固定相机转台提供稳定的 3D 视角旋转。

## 当前阶段

已完成核心实现、兰花完整帧时间切片资产、时间隧道空间构图、丰富动效、Git 远程管理和结构化工程记忆；当前网页不加载中央实时模型，后续以真实设备验证和部署为主。

## 主要用户或使用者

项目作者与访问作品页的体验者。

## 核心目录

| 路径 | 用途 |
| --- | --- |
| `src/` | Three.js 场景、时间轴、交互和样式 |
| `public/assets/` | 自包含 GLB、166 张透明 PNG 和清单 |
| `scripts/` | Blender Alembic 缓存到 GLB/PNG 的导出脚本 |
| `wiki_memory/` | 结构化工程记忆、决策、知识和日志 |

## 重要入口

- `index.html`：单一主界面入口。
- `runStart.cmd`：Windows 双击启动入口。
- `src/main.js`：Three.js 场景、滚动时间轴、拖拽旋转和切片展开。
- `src/style.css`：粉彩舞台、雾光和 CSS 动效。
- `scripts/export_blender_assets.py`：重新生成运行资产。
