# 系统架构

## 架构概览

Blender 导出层从 `BUTTERFLY_FLAP_FAST_FOLLOW_PATH_1_WING_FLAP_ONLY.blend` 的 `ARTIST_EDIT` 场景读取 1 到 91 帧。固定正交相机沿世界 Z 轴正对 X-Y 平面，并以蝴蝶身体包围盒中心为目标，每个整数帧输出一张 768×768 RGBA PNG。浏览器读取 manifest 后创建 91 个水平 X-Z 平面，每个平面在创建时永久绑定自己的纹理；平面沿世界 Y 轴分层，法线一致、彼此平行且不相交。

## 运行数据流

1. 页面校验 manifest 的 `sampleMode: every-integer-frame`、`view: fixed-top-front`、`displayPlane: xz-horizontal` 和 `timelineAxis: y`。
2. 91 张 PNG 分批载入并分别传入 91 个 `MeshBasicMaterial`；运行循环不修改材质的 `map`。
3. 滚轮、方向键和播放按钮只改变 `shuttleTarget`，相机焦点沿 Y 轴移动到对应实体平面。
4. 中心区域鼠标左键径向拖拽改变相邻平面的 Y 轴间距；展开到总览状态时相机退远并自动转到斜侧视角，让水平层级可见。
5. Three.js `OrbitControls` 负责左键旋转、右键平移和中键缩放；普通滚轮由应用截获为逐帧穿梭，`Control/Command + 滚轮` 保留为镜头缩放。

## 模块关系

| 模块 | 职责 | 入口 |
| --- | --- | --- |
| 页面 | 单屏结构、状态、按钮和无障碍说明 | `index.html` |
| Three.js | 静态纹理平面、穿梭、展开、原生三维相机、环境 | `src/main.js` |
| 样式 | 粉彩空间、控制器和响应式表现 | `src/style.css` |
| Blender 导出 | 固定 X-Y 正视、逐整数帧采样和原子发布 | `scripts/export_butterfly_slices.py` |

## 运行与部署

开发运行 `npm run dev`，生产构建运行 `npm run build`。静态部署必须同时提供 manifest 与 `frame-001.png` 到 `frame-091.png`。
