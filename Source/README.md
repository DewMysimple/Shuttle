# Source / 源素材

本目录用于管理蝴蝶时间切片的离线源素材和视觉参考文件：

- `BUTTERFLY_FLAP_FAST_FOLLOW_PATH_1.blend`：Blender 动画源文件。
- `留下的记忆切成时间切片 蝴蝶飞过的时间，切成了76片每一片都是飞行中的一个瞬间。滚动逐帧穿过，向外拖拽，就能看到整段蝴蝶飞行动画被展开.mp4`：第一段视觉参考。
- `时间切片 #threejs #vibecoding大赏 #抖音前沿科技首发计划 #编程艺术.mp4`：第二段视觉参考。

这些文件只用于离线采样、复盘和重新导出，不提交到 Git；网页运行时使用 `public/assets/` 中已生成的 PNG 和清单。重新导出时，从项目根目录执行 `README.md` 中的 Blender 命令。
